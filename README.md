# 🚀 Featured Project

## 🏭 Industrial Safety Copilot

> **AI-powered industrial safety inspection and decision-support system**

An end-to-end AI system combining **Computer Vision + RAG + LLM + Agentic AI + Cloud/MLOps concepts** to analyze industrial safety violations.

### 🔥 Architecture

```text
                 ┌─────────────────────┐
                 │   CCTV / Image      │
                 └──────────┬──────────┘
                            │
                            ▼
                 ┌─────────────────────┐
                 │     YOLO / CV       │
                 │  PPE Detection      │
                 └──────────┬──────────┘
                            │
                            ▼
                 ┌─────────────────────┐
                 │ Incident Generator  │
                 │ Risk Assessment     │
                 └──────────┬──────────┘
                            │
                            ▼
              ┌──────────────────────────┐
              │       RAG Pipeline       │
              │                          │
              │ Safety Manuals           │
              │ SOPs                     │
              │ PPE Policies             │
              │ Emergency Guidelines     │
              └────────────┬─────────────┘
                           │
                           ▼
                 ┌─────────────────────┐
                 │ PostgreSQL +        │
                 │ pgvector            │
                 └──────────┬──────────┘
                            │
                            ▼
                 ┌─────────────────────┐
                 │      LLM            │
                 │ Explanation +        │
                 │ Corrective Action    │
                 └──────────┬──────────┘
                            │
                            ▼
                 ┌─────────────────────┐
                 │     LangGraph       │
                 │   Agent Workflow    │
                 └──────────┬──────────┘
                            │
                            ▼
                 ┌─────────────────────┐
                 │ Safety Report       │
                 │ Risk + Evidence     │
                 └─────────────────────┘
```

### 🎯 Key Capabilities

* 👷 Detect workers and PPE violations
* 🪖 Helmet detection
* 🦺 Safety-vest detection
* 🥽 Safety-equipment analysis
* ⚠️ Automatic incident generation
* 📊 Risk scoring and prioritization
* 🔎 Hybrid RAG search
* 📚 Safety-policy retrieval
* 🧠 LLM-based explanation
* 🤖 Agentic workflow with LangGraph
* 🗄️ PostgreSQL + pgvector
* 🔐 Evidence-based responses to reduce hallucinations
